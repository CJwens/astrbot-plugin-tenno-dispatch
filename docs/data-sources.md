# 数据源核验记录

核验日期：2026-11-06

## 世界状态

- 来源：WFCD / WarframeStat.us 社区 API，国际服 PC 路径 `https://api.warframestat.us/pc/{endpoint}`。
- 本插件使用：`fissures`、`sortie`、`arbitration`、`alerts`。
- 官方性：非 Digital Extremes 官方 API；WFCD 的接口规格公开，但服务可用性和字段格式仍由社区维护。
- 登录：本插件不登录 Warframe，也不请求用户账号凭据。
- 缓存：成功响应缓存 60 秒；请求失败时，如有缓存，最多回退到 15 分钟内的数据，并在回复中标明缓存。
- 当前验证限制：开发执行环境访问 `api.warframestat.us` 返回 HTTP 403，因此本次无法从该环境确认线上响应和各端点字段。部署环境需实测；插件对可选字段采用容错处理。
