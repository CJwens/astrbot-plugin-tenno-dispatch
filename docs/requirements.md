# 首版需求

## 目标

为 AstrBot 提供可在群聊中调用的《星际战甲》世界状态查询命令。插件名为“天诺通讯”，与聊天平台解耦，可先在本地 AstrBot 测试，再接 QQ。

## 首版范围

- `wf`：显示帮助。
- `wf 裂隙`：查询虚空裂隙。
- `wf 突击`：查询突击任务。
- `wf 仲裁`：查询仲裁任务。
- `wf 警报`：查询警报。
- 使用国际服 PC 数据，依赖外部数据源时明确提示来源暂不可用。
- 使用 60 秒内存缓存；接口失败时最多回退到 15 分钟内缓存，并标记缓存数据。
- 不要求、不保存 Warframe 账号信息。

## 暂不在首版范围

- 每周无尽任务排行榜：尚未确认 DE 公开接口和匿名访问方式。
- WM 价格、紫卡分析、AI 聊天、定时推送和通知订阅。
- 国服或主机数据保证。

## 验收

- AstrBot 可加载插件，支持的命令能触发对应回复。
- 空响应、接口超时、HTTP 错误和非预期 JSON 不导致插件崩溃。
- 过期缓存会被显式标记，不冒充实时数据。
- 纯格式化逻辑可脱离 AstrBot 运行单元测试。
